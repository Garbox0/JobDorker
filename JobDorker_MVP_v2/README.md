# JobDorker 2.0

Aplicación de escritorio gratuita para búsquedas avanzadas de empleo y seguimiento local de oportunidades. No requiere login ni registro.

La IA es opcional: cada persona ingresa su propia API key en la aplicación. La clave no se guarda.

## Ejecutar desde código

```bash
python -m venv .venv
.\.venv\Scripts\Activate
pip install -r requirements.txt
python JobDorker.py
```
